# தமிழ்நாடு மளிகைக் கடை ஜிஎஸ்டி பில்லிங் சாப்ட்வேர்
## Tamil Nadu Grocery Store GST Compliant Billing Software (Bilingual Tamil & English)

தமிழ்நாடு மளிகைக் கடைகள், சூப்பர் மார்க்கெட்டுகள் மற்றும் பலசரக்கு கடைகளுக்கான முழுமையான, வேகமான, 100% ஆஃப்லைனில் இயங்கக்கூடிய ஜிஎஸ்டி பில்லிங் மென்பொருள்.

A high-speed, 100% offline-capable, GST compliant Point of Sale (POS) and inventory billing software specially engineered for grocery stores, supermarkets, and provision stores in **Tamil Nadu (State Code: 33)**.

---

## 🌟 சிறப்பம்சங்கள் (Key Features)

### 1. தமிழ் & ஆங்கிலம் இருமொழி ஆதரவு (Complete Bilingual Support)
- **UI Language Switch**: ஒரே கிளிக்கில் முழு மென்பொருளையும் தமிழில் அல்லது ஆங்கிலத்தில் மாற்றிக்கொள்ளலாம்.
- **Bilingual Grocery Catalog**: 60+க்கும் மேற்பட்ட பொதுவான மளிகைப் பொருட்கள் (பொன்னி அரிசி, துவரம் பருப்பு, ஆவின் பால், இதயம் நல்லெண்ணெய், சக்தி சாம்பார் பொடி, சர்க்கரை, முதலியன) தமிழ் மற்றும் ஆங்கில பெயர்களுடன் ஏற்கனவே சேர்க்கப்பட்டுள்ளன.
- **Bilingual Receipts**: வாடிக்கையாளர் ரசீதுகளில் தமிழ் மற்றும் ஆங்கிலத்தில் பொருட்களின் பெயர் அச்சிடப்படும்.

### 2. தமிழ்நாடு ஜிஎஸ்டி விதிகள் (Tamil Nadu GST Compliance - State 33)
- **மாநில உள் விற்பனை (Intra-State Sales)**: 
  - CGST 50% + SGST 50% தானியங்கி கணக்கீடு (0%, 5%, 12%, 18%, 28% வரி அடுக்குகள்).
  - மளிகைக் கடை MRP விலையில் வரி அடங்கிய கணக்கீடு (Tax-Inclusive back-calculation).
- **HSN குறியீடு அட்டவணை**: ஜிஎஸ்டி சட்டப்படி கட்டாயமான HSN வாரியான வரி சுருக்க அட்டவணை (HSN Summary Table) ரசீதுகளில் தானாகவே உருவாக்கப்படும்.
- **ரவுண்ட் ஆஃப் (Round-Off)**: ஜிஎஸ்டி சட்டப்பிரிவு 170-ன் படி அருகிலுள்ள முழு ரூபாய்க்கு சமப்படுத்துதல்.
- **GSTR-1 அறிக்கைகள் (CA / Auditor Ready)**:
  - **Table 7 (B2CS)**: சில்லறை நுகர்வோர் விற்பனை வரி விகித வாரியாக (Taxable Value, CGST, SGST, Total).
  - **Table 4 (B2B)**: ஜிஎஸ்டி எண் கொண்ட வணிக வாடிக்கையாளர் ரசீதுகள்.
  - **Table 12 (HSN Summary)**: HSN வாரியான பொருட்கள் விற்பனை, UQC அளவுகள் (KGS, PAC, LTR, NOS).
  - Excel / CSV வடிவத்தில் ஒரே கிளிக்கில் பதிவிறக்கம்.

### 3. அதிவேக பில்லிங் (Superfast POS Counter Workflow)
- **பார்கோடு ஸ்கேனர் & விசைப்பலகை குறுக்குவழிகள் (Hotkeys)**:
  - **F2**: புதிய பில் (New Bill)
  - **F4**: பார்கோடு / தேடல் பெட்டிக்கு செல்ல (Focus Search / Barcode)
  - **F8**: பில் சேமிக்க மட்டும் (Save Bill)
  - **F9**: பில் சேமித்து தெர்மல் பிரிண்ட் எடுக்க (Save & Print)
  - **F10**: பில் நிறுத்தி வைக்க (Hold / Recall Bill)
- **எடை பொருட்கள் உள்ளீடு (Loose Items / Weight Entry)**:
  - அரிசி, சர்க்கரை, பருப்பு போன்ற தளர்வான பொருட்களுக்கு 100g, 250g, 500g, 1kg, 2kg அல்லது விருப்பமான எடையை நொடியில் உள்ளிடும் வசதி.
- **ரொக்கம் & மீதி கணக்கீடு**: பெற்ற ரொக்கத்தை உள்ளிட்டால் திரும்பத் தர வேண்டிய மீதித் தொகை உடனே கணக்கிடப்படும்.

### 4. தானியங்கி UPI QR கோடு (Dynamic QR Code for GPay / PhonePe / Paytm)
- வாடிக்கையாளர் ரசீதில் மற்றும் பில்லிங் திரையில் துல்லியமான பில் தொகைக்கான UPI QR கோடு தானாக உருவாக்கப்படும். வாடிக்கையாளர் மொபைலில் ஸ்கேன் செய்து உடனடியாக பணம் செலுத்தலாம்.

### 5. ரசீது & அச்சிடும் முறைகள் (Printing Formats)
- **80mm (3 அங்குலம்) தெர்மல் ரசீது**: சூப்பர் மார்க்கெட் தெர்மல் பிரிண்டர்களுக்கு உகந்தது.
- **58mm (2 அங்குலம்) மினி தெர்மல் ரசீது**: சிறிய கடைகளுக்கான ரசீது.
- **A4 ஜிஎஸ்டி வரி ரசீது (Tax Invoice)**: B2B மற்றும் மொத்த விற்பனைக்கான விரிவான வரி ரசீது.

### 6. வாடிக்கையாளர் கடன் பதிவேடு (Credit Ledger)
- வாடிக்கையாளர்களுக்கு கடன் கணக்கு வைத்தல்.
- முந்தைய பாக்கி தொகை, வாங்கிய பொருட்கள் மற்றும் செலுத்திய தொகைகளுக்கான தனி லெட்ஜர்.

## 🚀 மென்பொருளைத் தொடங்குவது எப்படி? (How to Launch)

### ⭐ 100% தனித்தியங்கும் விண்டோஸ் மென்பொருள் (Independent Desktop Software)
இந்த மென்பொருள் எந்த உலாவியிலும் (Chrome, Edge, Firefox) இயங்காமல், **முழுமையான தனிப்பட்ட விண்டோஸ் சாப்ட்வேர் சாளரமாக (Native Independent Desktop Application Window)** இயங்கும்.

**இயக்குவதற்கு இரண்டு வழிகள்:**
1. கோப்புறையின் முகப்பில் உள்ள **`TamilNaduGroceryBilling.exe`** கோப்பை இரட்டை கிளிக் செய்யவும்.
2. அல்லது **`TamilNaduGroceryBilling/TamilNaduGroceryBilling.exe`** கோப்பை நேரடியாக இயக்கலாம்.

#### சிறப்பம்சங்கள்:
- ❌ எந்தவித இணைய உலாவியும் (Browser) திறக்காது.
- ❌ முகவரிப் பட்டி (URL bar), டேப்கள் எதுவும் கிடையாது.
- ✔️ சொந்த சாளரம் (Dedicated Window), சொந்த டாஸ்க்பார் ஐகான், முழுத் திரை பிஓஎஸ் (POS) வசதி.
- ✔️ 100% ஆஃப்லைனில் இயங்கும் - இணையம் தேவையில்லை.
- ✔️ `TamilNaduGroceryBilling` கோப்புறையை அப்படியே பென்டிரைவில் எடுத்துச் சென்று எந்த விண்டோஸ் பிசியிலும் இயக்கலாம்.

### முறை 2: கமாண்ட் லைன் மூலம் (Developer Mode)
```bash
npm start
```
உலாவியில் இயக்க: `http://localhost:5000`

## 🗄️ தொழில்நுட்பக் கட்டமைப்பு (Tech Stack)
- **Backend**: Node.js v24, Express, `node:sqlite` (உள்ளமைக்கப்பட்ட SQLite டேட்டாபேஸ், அதிவேக WAL மோட்).
- **Frontend**: React 19, Vite, Tailwind CSS, Lucide Icons, QR Code Generator.
- **Offline Reliability**: 100% உள்ளூர் கணினியிலேயே இயங்கும், இணைய சேவை தேவையில்லை.
